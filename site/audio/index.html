تنزيل التلاوات

كل تلاوة وُقِّتت هنا، سورةً أو مجموعة سور أو ختمةً كاملة، ومعها ملفات توقيتها إن شئت. الملفات تُنزَّل من الخادم الذي يستضيفها مباشرة: خادمنا للختمات الليبية، وmp3quran.net لتلاواته.

Download the aligned recitations, one surah, a selection or a whole khatma, optionally with their word and ayah timings. Files come straight from where each recording is hosted.

التلاوات لأصحابها (المصدر مذكور تحت كل قارئ). هي متاحة هنا للاستماع والدراسة والبحث مع التوقيتات؛ وإعادة نشرها تحتاج إذن الناشر. التوقيتات نفسها CC BY 4.0.

من سطر الأوامر

لكل قارئ زر «قائمة الروابط» يعطي ملف urls.txt بروابط ما اخترته (أو الختمة كلها)، ثم:

# macOS / Linux: يكمل ما انقطع ويتخطّى الموجود
wget -c -nc -i urls.txt

# أو
xargs -n 1 curl -fLO -C - < urls.txt

# Windows PowerShell
Get-Content urls.txt | ForEach-Object { Invoke-WebRequest $_ -OutFile (Split-Path $_ -Leaf) }

والقائمة كاملة بصيغة آلية في /audio/index.json: لكل قارئ قالب رابط الصوت، وحجم كل سورة بالبايت، وروابط توقيتها.
